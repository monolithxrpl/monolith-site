Selling a Tile

Seller controls are wallet-protected. Use the wallet that currently owns the coordinate and its deed.

Ownership Changed

MONOLITH ownership-sensitive features depend on current wallet ownership. If ownership has changed, protected seller or owner actions may stop until the new state is recognized.

Market Transaction Issue

Keep the coordinate, public wallet addresses involved and XRPL transaction hash. Do not repeat a payment simply because the browser has not updated yet.

$XRP Payments & Xaman

MONOLITH uses the XRP Ledger for wallet authentication and transaction settlement.

Xaman Sign-In

Signing a MONOLITH sign-in request proves control of the public XRPL wallet. It does not require sharing your seed phrase or private key.

Payment Pending

A signed request is not automatically treated as payment. MONOLITH verifies the validated XRPL transaction before completing payment state.

Payment Failed

Do not manually send another payment unless the MONOLITH flow specifically tells you to. Keep the transaction hash and contact support if funds were already sent.

Direct Tile Payments

Claimed tiles can support direct $XRP payment utilities. Always verify the destination and amount shown in Xaman before signing.

Browser & Technical Help

Xaman Doesn't Open

  • Use Safari, Chrome or another normal browser.
  • Avoid embedded social-media browsers.
  • Make sure Xaman is installed and current.
  • Retry the MONOLITH action from the original page.

Page Looks Outdated

  • Refresh the page.
  • Close and reopen the browser tab.
  • Try a private or incognito window.
  • Verify that you are on monolithxrpl.com.

Wrong Wallet

Protected MONOLITH actions must use the wallet that owns or controls the relevant coordinate, order or seller account.

Unexpected Error

Stop before repeating a payment. Capture the exact message shown, the page you were using and any related transaction hash, then contact support.

MONOLITH Security Rules

MONOLITH will never ask for your wallet seed phrase or private key. Review every Xaman request before signing. Verify that you are using monolithxrpl.com. Public wallet addresses and XRPL transaction hashes are safe to provide when support needs them to investigate an issue.

Contact MONOLITH Support

If the Help Center does not solve the problem, send enough information for the issue to be investigated without exposing private wallet credentials.

  • The MONOLITH coordinate, order ID or page involved
  • Your public XRPL wallet address if relevant
  • The XRPL transaction hash if money moved
  • A screenshot or the exact error message
  • A short explanation of what you were trying to do
